# Python 实时对话运行器

一个网页应用：粘贴 Python 代码，在独立子进程中运行，并通过浏览器与它**实时对话**
（发一行文本 / 关闭标准输入 / 查看双路输出 / 随时终止）。

技术栈：Flask + 原生 HTML/CSS/JavaScript，无任何前端框架。

## 启动（一条命令）

```bash
docker compose up --build
```

然后打开 **http://localhost:8000** （端口 **8000**）。

依赖（Flask）随容器启动时自动安装，见 `docker-entrypoint.sh`。

也可以不用容器，本机直接跑：

```bash
pip install -r requirements.txt
python app.py          # 监听 0.0.0.0:8000
```

## 功能与设计

- **立即返回运行标识**：`POST /api/runs` 启动子进程后立刻返回 `run_id`，
  输出通过 `GET /api/runs/<id>/poll?out_pos=&err_pos=` 增量轮询。
- **双路增量输出**：stdout / stderr 各由一个守护线程读取原始字节，
  分别用 UTF-8 **增量解码器**解码——未换行的内容即时显示，
  跨片段的多字节字符不丢字、不乱码；前端按字符位置增量拼接。
- **实时对话**：可发送一行文本到子进程标准输入；可关闭标准输入（EOF），
  关闭后写入会被拒绝（HTTP 409）。
- **互不阻塞**：等待输入或一路无输出时，另一路输出、状态查询、终止照常处理。
- **全站仅一个未结束运行**：有未结束运行时，新的启动请求返回 409。
- **先排空再公布**：正常退出与主动终止都会先排空两路输出、回收子进程，
  之后才公布退出码并允许下一次运行。
- **终止不等待**：先 SIGTERM，1 秒内不退出就 SIGKILL，绝不等程序自行退出。
- **旧标识无效**：旧 `run_id` 对新进程没有任何控制权（一律 404）；
  前端校验响应里的 `run_id`，迟到回包不会混入新一轮页面。
- **状态全在内存**：服务重启即清空，没有持久化。

## 内置示例（页面右上角可载入）

| 示例 | 演示点 |
| --- | --- |
| 等待输入（回显对话） | 程序阻塞在 `sys.stdin`，期间仍可轮询、可终止 |
| 双路无换行输出 | stdout/stderr 都不带换行，增量呈现不丢字 |
| EOF（读到底） | `sys.stdin.read()` 直到关闭标准输入才继续 |
| 终止（忽略 SIGTERM 的死循环） | 终止自动升级为 SIGKILL，并排空输出后公布退出码 |

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/runs` | 启动运行，body `{"code": "..."}`，返回 `{"run_id": "..."}`；已有未结束运行时 409 |
| `GET` | `/api/runs/<id>/poll?out_pos=N&err_pos=M` | 增量拉取两路输出与状态（含退出码） |
| `POST` | `/api/runs/<id>/stdin` | 写入一行，body `{"line": "..."}`；已关闭/已结束返回 409 |
| `POST` | `/api/runs/<id>/stdin/close` | 关闭标准输入（EOF） |
| `POST` | `/api/runs/<id>/terminate` | 终止运行；返回时进程已回收、输出已排空 |

## 适用范围与免责

仅面向**本机可信、不派生进程、只用标准库**的代码：子进程与 Flask 同权限运行，
**没有任何安全沙箱**，请勿把本服务暴露到不可信网络或执行不可信代码。
